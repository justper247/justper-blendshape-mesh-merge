# BlendShape Mesh Merge

Version 1.8.4

Merges accessories with an avatar mesh during preview and upload. Original files stay unchanged.

1. Place the accessory inside your avatar.
2. Keep **Merge Into** on **Face Mesh (Automatic)**, or choose another mesh.
3. Add the accessory meshes.
4. Check the **Ready** message, then preview or upload.

**Advanced Settings** contains mesh selection, bone connection, speech matching, and manual shape matches. **Details** shows blendshape and PhysBone counts.

Matching blendshape names work automatically. Existing PhysBone chains are preserved.
