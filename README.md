# Justper BlendShape Mesh Merge

Non-destructively combines accessory meshes with a VRChat avatar mesh during Play Mode and avatar builds.

Install it from the Justper package source in VCC or ALCOM.

## Releasing an update

1. Update the version in `Packages/com.justper.blendshape-mesh-merge/package.json`.
2. Commit and push the changes.
3. Run the `Build Release` action on GitHub.
